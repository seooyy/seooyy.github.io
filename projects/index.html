    OIBC 2026 | 태양광 집합자원 구성·발전량 예측

    POSTECH OIBC·4인 팀·시계열 예측

    문제 정의
    태양광 발전소 253곳을 두 집합으로 나누고, 집합별 시간당 발전량을 하루 전에 예측해야 했습니다. 예측 오차에 전력가격과 시간대 가중치를 곱한 값이 감점이 되는 정산 방식이었습니다.
    역할
    aggregation_model 파이프라인을 맡아 실험 약 70개를 설계하고 실행했습니다. 기상 예보 2종을 합친 LightGBM(L1, 용량 가중) 예측 모델, 발전소 간 오차가 서로 상쇄되도록 하는 집합 배정 최적화, TabM 혼합, 외부 NOAA GFS 일사·운량 특징을 개발했습니다. GFS 특징에는 제출 마감 전에 공개된 실행분만 쓰는 규칙을 적용했습니다.
    결과
    같은 Local test 기간에서 기준선(baseline 재현) 대비 감점을 약 20% 줄였습니다(2.24억 원 → 1.79억 원). 실험마다 프롬프트, 설정, 보고서, 누적 결론을 남기는 방식으로 실험 기록을 관리했고, 검증을 통과한 제출 파일까지 만들었습니다.
    기술
    • Python
    • LightGBM
    • TabM
    • NOAA GFS
    • Pandas/Parquet

    한 끼 리밸런싱 | 외식업 판매전략 추천

    BC카드 소비데이터 공모전·3인 팀·Data

    문제 정의
    매출이 줄었을 때 원인을 확인하지 않고 할인부터 하면 판매량이 늘어도 이익이 줄 수 있습니다. 음식점 사업자가 지역 소비 변화를 보고 무엇부터 시도할지 고를 수 있는 도구가 필요했습니다.
    역할
    기획안, 실행 계획, 3인 작업 계약 문서를 작성했습니다. BC카드 소비데이터 로더를 만들고, 지역·업종·소비집단별로 결제건수와 건당금액 변화를 전국 대비 초과분으로 판정하는 진단 로직과 실행 후보 게이트를 구현했습니다.
    결과
    255개 시군구 전체의 진단 결과를 산출했습니다. 이천시 서양음식은 건당금액이 전국보다 4.72%p 더 떨어져 255개 지역 중 4번째로 낮다는 것을 찾았고, 이를 할인이 아닌 대안이 필요한 객단가 문제 사례로 정리했습니다. 진단 결과는 손익 시뮬레이터의 대안 추천으로 연결됩니다.
    기술
    • Python
    • pandas
    • Streamlit
    • pytest

    세탁 기호 탐지 모델 | YOLOv8 → Android TFLite

    2026-1학기 Android 텀 프로젝트·객체 탐지

    문제 정의
    옷의 세탁 라벨에 있는 기호만 보고는 세탁 방법을 바로 알기 어렵습니다. 라벨 사진에서 세탁 기호를 자동으로 찾아, Android 앱에서 세탁 방법을 안내할 수 있는 모델이 필요했습니다.
    역할
    Roboflow 세탁 기호 데이터셋(이미지 624장, 70개 클래스)의 라벨 이름을 [국가/표준]_[기능]_[세부조건] 규칙으로 정리하고, Google Colab에서 YOLOv8s를 학습했습니다. 세탁 기호는 뒤집으면 뜻이 바뀌기 때문에 좌우·상하 반전 증강을 끄고 학습했고, 학습한 모델을 Android에서 쓸 수 있도록 NMS를 포함한 TFLite 모델로 변환했습니다.
    결과
    검증 데이터에서 mAP50 0.808, 테스트 데이터에서 mAP50 0.605를 기록했고, 추론 속도는 이미지당 약 10ms(Tesla T4)였습니다. 학습 데이터가 많은 한국 기호(KR_) 클래스는 대부분 mAP50 0.85 이상이었고, 샘플이 1~5개뿐인 클래스는 성능이 낮아 데이터 보강과 클래스 병합을 다음 과제로 정리했습니다.
    기술
    • Python
    • YOLOv8(Ultralytics)
    • PyTorch
    • TensorFlow Lite
    • Roboflow
    • Google Colab
