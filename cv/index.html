자기소개

데이터 분석 분야를 목표로 하는 부산대학교 컴퓨터공학 전공생 정서영입니다. 카드 소비데이터로 지역·업종별 매출 변화의 원인을 진단하고, 기상 예보 데이터로 태양광 발전량을 예측하는 등 실제 데이터를 다루는 프로젝트를 해 왔습니다. 집계 오류를 막는 검증 규칙을 먼저 세우고, 실험 결과를 기록하며 근거를 쌓는 방식으로 일합니다.

학력

부산대학교 · 컴퓨터공학 전공

2024.03 – 재학 중

프로젝트 경험

OIBC 2026 · 태양광 집합자원 구성·발전량 예측

2026.11 · POSTECH OIBC · 4인 팀 · 예측 모델 실험 담당

  • 집합 예측 파이프라인을 맡아 실험 약 70개를 설계하고 실행했습니다.
  • 기상 예보 2종을 합친 LightGBM 모델, 오차가 상쇄되도록 발전소를 나누는 집합 배정 최적화, NOAA GFS 일사·운량 특징을 개발했습니다.
  • 기준선 대비 감점을 약 20% 줄였습니다(2.24억 원 → 1.79억 원).

한 끼 리밸런싱 · 외식업 판매전략 추천

2026.08 – 2026.09 · BC카드 소비데이터 공모전 · 3인 팀 · 데이터 처리·진단 담당

  • 255개 시군구의 카드 소비데이터를 처리하고 집계하는 Python 파이프라인을 만들었습니다.
  • 지역·업종 집계 오류를 막는 검증 규칙을 추가했습니다.
  • 전국 대비 변화를 기준으로 판매전략 후보를 고르는 규칙 기반 진단 로직을 개발했습니다.

말꼬리 · AI 발표 리허설

2026.07 · 몰입캠프 · 3인 팀 · 백엔드 담당

  • 인증, 팀, 발표 세션 API를 구현했습니다.
  • 음성 인식 작업 큐와 비동기 질의응답 처리를 구현했습니다.

AID-Fit · AI 패션 코디 추천

2026.03 – 2026.08 · 수업 프로젝트 · 4인 팀 · Vision/VLM 담당

  • VLM으로 의류의 종류, 색상, 소재, 핏, 패턴, 분위기, 계절 속성을 추출하는 파이프라인을 개발했습니다.
  • 단일 의류와 코디 사진 속 여러 의류를 분석해 추천 시스템이 쓰는 구조화 데이터로 바꿨습니다.
  • 모델 출력을 표준화하고 의류가 아닌 이미지를 걸러 입력 데이터를 검증했습니다.
  • 같은 이미지는 기존 분석 결과를 재사용해 불필요한 VLM API 호출을 줄였습니다.
